# The Mall: world generation knobs
#
# What shapes the chunks the mall grows: how likely each kind is, room
# sizes, plazas, water, traps, machines, toilets, statues. The game reads
# this at start and F5 reads it again; chunks grown from then on follow
# the new values, those already grown stay. `make genview` turns these
# knobs with a live preview.
#
# Format:
#   [section]               the file of src/world/ the knobs below belong to
#   # comment               the lines just above a knob tell what it does
#   NAME  value...  lo..hi  its value, or several for a list, and the range
#                           the editor keeps it in
# Sizes and distances are in cells (6 px), chances from 0 to 1. A value
# may be a fraction such as 1/3. Weights are relative: only how they
# compare matters. Changing a value changes the game, so `make check`
# fails after it, and `make golden` rewrites the golden output.
