# The game's music, written like a tiny tracker and played through the same
# synth as the sounds (src/audio/music_data.h). F5 reads it again.
# `make musicsheet` renders each section alone, and each song as the game
# would play it, to build/music/.
#
#   crush BITS RATE     every song after this is crushed to BITS bits a
#                       sample at RATE samples a second, as the sounds are
#   song NAME [tempo BPM] [rows R] [wow CENTS] [gain G] [bits B] [rate R]
#                       starts a song; the code plays it by NAME. tempo is
#                       beats a minute (90), rows how many rows a beat (4),
#                       wow how far the old tape drifts out of tune (0),
#                       gain how loud the whole mix is before the crush (1)
#   instrument NAME [gain G] [detune CENTS] [sustain]
#                       an instrument, its layers on the lines under it,
#                       written as in data/sounds.txt at A4 (440 Hz): each
#                       note moves them to its pitch. sustain holds a note
#                       for as long as it is written; otherwise it is struck
#                       and rings as its layers do
#   channels NAME[:CENTS] ...
#                       the song's channels, an instrument each, maybe a few
#                       cents out of tune of their own
#   section NAME        a section, its rows on the lines under it: a cell
#                       per channel, each a note (C-4, Db4: flats, as # starts
#                       a comment), x (a hit at the pitch its instrument was
#                       written at), . (nothing new: what plays rings on) or
#                       == (stop). A note plays until the next in its channel
#                       or a stop, and rings on past the end of its section
#   flow FROM TO WEIGHT [TO WEIGHT ...]
#                       what may follow a section, likelier the heavier;
#                       a section with no flow is followed by the next one
#   vary drop CHANCE [keep NAME ...]
#                       each time a section starts (but the first), each
#                       channel may drop out this often, but those playing
#                       the kept instruments
#
# The song starts at its first section, as written.

crush 5 8000
