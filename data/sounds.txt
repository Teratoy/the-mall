# Every sound in the game, made from a few numbers (src/audio/synth.h).
# F5 in the game reads this file again. `make soundsheet` renders each
# sound to build/sounds/NAME.wav to listen to.
#
#   crush BITS RATE     every sound after this is crushed to BITS bits a
#                       sample at RATE samples a second: the old-console sound
#   sound NAME [gain G] [bits B] [rate R]
#                       starts a sound; the code plays it by NAME
#   WAVE FROM [TO] [key value ...]
#                       a layer of the sound above. WAVE is square, triangle,
#                       saw, sine or noise. FROM and TO are Hz, slid from one
#                       to the other (noise takes a new value twice a period:
#                       low rumbles, high hisses). Keys, in seconds and Hz:
#                         gain      how loud, 0 to 1 (0.5)
#                         delay     wait before it starts (0)
#                         attack    rise (0.002)  hold  held (0)  decay  fall (0.1)
#                         lowpass   keep only what is under this (none)
#                         highpass  keep only what is over this (none)
#                         duty      a square's share high, 0 to 1 (0.5)
#                         repeat    played this many times (1), gap apart (0.1),
#                         gap fade  each fade times as loud as the last (1)
#                         wobble    pitch wandering at random, 0 to 1: crunch
#
# Heard through a wall, a sound is dulled before the crush.

crush 5 8000

# --- Feet. One step each time a foot comes down in the walk or run art.

sound step
    noise 1400 600 gain 0.5 decay 0.035 lowpass 2600
    square 140 70 gain 0.25 decay 0.03 duty 0.3

sound run gain 1.2
    noise 1800 700 gain 0.55 decay 0.04 lowpass 3000
    square 150 60 gain 0.35 decay 0.04 duty 0.3

# Fresh piss or poured water underfoot.
sound step_wet
    noise 2600 900 gain 0.5 attack 0.005 decay 0.08 lowpass 3500 highpass 400 wobble 0.4
    sine 500 260 gain 0.2 decay 0.05

# Wet blood underfoot: tacky, and a little suck as the foot lifts.

    noise 900 400 gain 0.5 attack 0.004 decay 0.07 lowpass 1800 wobble 0.6
    sine 300 160 gain 0.3 decay 0.05
    noise 2400 1200 gain 0.2 delay 0.07 attack 0.01 decay 0.04 lowpass 3000

# Fresh feces underfoot.
sound step_filth
    noise 700 250 gain 0.6 attack 0.006 decay 0.1 lowpass 1300 wobble 0.8
    sine 180 90 gain 0.35 decay 0.08
