# Every sprite the game draws from letters, read at start and again on F5
# in the game. The sprite editor (make sprites, or sprites.sh) edits it, but
# it is plain text and can be edited by hand too.
#
# A sprite is:
#   sprite NAME            the name the game looks it up by
#   # ...                  what it is, and what the game does with its letters
#   ink L RRGGBB [what]    the colour of letter L, RRGGBBAA if see-through
#   blink A B              letters A and B trade colours on every other blink
#   rows of letters        '.' is see-through; every row as wide as the first
# group NAME only sorts the sprites into groups for the editor.
#
# The game draws each sprite at a fixed size, so keep its rows and columns:
# one the wrong size is reported and kept as it was. A colour the game
# changes as it draws (dimmed when remembered, dirt, blood) is changed from
# these.
